# WEBSITE RASA NUSANTARA

## Deskripsi Projek

Rasa Nusantara dibuat untuk memperkenalkan berbagai makanan khas dari beberapa daerah di Indonesia melalui informasi resep yang sederhana dan mudah dipahami. Website ini menyediakan beberapa halaman yang berisi kategori daerah, daftar makanan dan resepnya, serta halaman kontak untuk memberi saran dan kritik.

## Tujuan

- Memperkenalkan masakan khas dari berbagai daerah di Indonesia
- Menyediakan informasi resep makanan sederhana
- Menerapkan penggunaan HTML dan CSS dalam pembuatan website
- Menerapkan konsep responsive web design

## Daftar Halaman

- Beranda
  Halaman utaman dan pengenalan website
- Jawa
  Kumpulan resep makanan khas Jawa. Resepnya yaitu Rawon, Nasi Pecel, dan Soto Lamongan.
- Banjar
  Kumpulan resep makanan khas Banjar. Resepnya yaitu Soto Banjar, Ketupat Kandangan, dan Mie Bancir.
- Padang
  Kumpulan resep makanan khas Padang. Resepnya yaitu Rendang, Ayam Pop, dan Dendeng Balado.
- Kontak
  Halaman kontak dan formulir. Ini tersambung ke halaman notifikasi berhasil.
